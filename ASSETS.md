# Game assets

The website includes textures and inventory renders from the user's Minecraft 1.6.4 TechIt-ng installation. Minecraft and mod names, textures, and artwork belong to their respective owners. This project does not claim ownership of those assets and is not an official Minecraft product.

Game and mod JARs, decompiled source, installation configuration, raw runtime dumps, and personal world data are not included in this repository. The normalized recipe catalog and website images are included so deployments do not need a Minecraft installation.
